## 2. サービス内容

### 何をするか

企業のバックオフィス（管理部・総務部・経理部）の業務を、AIによって完全自動化する。

**提供価値**: 新卒1人分の人件費で、休まず・辞めず・ミスしない「AI新人社員」を配属する。

### 技術アプローチ

企業ごとにフルスクラッチで構築。以下を組み合わせて最適な自動化を実現する。

| アプローチ | 内容 |
|-----------|------|
| RPA的自動化 | Playwright等でブラウザ操作を自動化。既存システムをそのまま操作 |
| API連携 | freee、マネーフォワード、kintone等のSaaS間を繋ぐ |
| AIエージェント | Claude/GPTに業務判断をさせて自律的に処理 |
| カスタムシステム | 業務に合わせた専用ツールをゼロから構築 |
| PC丸ごとAI化 | AIに1台のPCを与え、ブラウザ・Office・Adobe等を人間同等に操作させる |

### 自動化レベル（AIの進化に合わせて拡大）

| レベル | 内容 | 例 | 対応時期 |
|--------|------|-----|---------|
| Lv1 | 定型データの転記 | 請求書 → 会計ソフト入力 | 現在対応可能 |
| Lv2 | ルールベースの判断+処理 | 仕訳の自動分類、承認ルート振り分け | 現在対応可能 |
| Lv3 | 非定型データの読み取り+処理 | 手書きFAX、バラバラな注文書の処理 | 次世代AIで対応 |
| Lv4 | 人間的判断を伴う業務 | 与信判断、クレーム一次振り分け | 次世代AIで対応 |
| Lv5 | 対外コミュニケーション | 取引先への発注メール、電話対応 | 将来対応 |

→ AIの進化に合わせて出来る範囲を上げていく。時代と状況に合わせて柔軟に対応。

## 3. ビジネスモデル

### 価格体系

| 項目 | 金額 | 備考 |
|------|------|------|
| **初期構築** | 100万円〜 / 月 | 1案件1ヶ月が基本。規模により最大3ヶ月 |
| **月額保守** | 初期構築費の15%（月額15万円〜） | AIチューニング・業務変更対応・障害復旧含む |

### ROI訴求（顧客への提案ロジック）

```
新卒社員1人の年間コスト（給与+社保+教育費） ≒ 400〜500万円
    ↓
AI新人の年間コスト（初期100万 + 保守15万×12ヶ月） = 280万円
    ↓
人件費の約半額。しかも24時間稼働・退職リスクゼロ。
```

### 案件の流れ

```
1. ヒアリング（出向1-2日）
   └ 現場の業務フローを観察・聞き取り
   └ 自動化対象の特定・スコープ決定

2. 構築（自宅 約1ヶ月）
   └ フルスクラッチで自動化システムを構築
   └ 企業の環境に合わせたカスタム実装

3. 導入（出向1-2日）
   └ 現地でセットアップ・動作確認
   └ 担当者へのレクチャー

4. 運用保守（自宅・月額契約）
   └ リモートデスクトップで遠隔保守
   └ AIチューニング・業務変更対応
```

### 案件スタイル

- **1社ずつ集中対応** — 品質を最優先
- **小粒で素早く成果を見せる** — 1ヶ月で1業務を完全自動化
- **信頼を積んで追加案件を獲得** — 気に入ってもらえたら別の業務も自動化
- **保守が積み上がるストック型** — AI進化で保守の手間が減り、抱えられる社数が増加

### 売上シミュレーション

```
【独立1年目（2027年）】
  初期構築: 年間6社 × 100万円 = 600万円
  月額保守: 平均3社 × 15万円 × 12ヶ月 = 540万円
  合計: 約1,140万円

【独立2年目（2028年）】
  初期構築: 年間8社 × 100万円 = 800万円
  月額保守: 平均8社 × 15万円 × 12ヶ月 = 1,440万円
  合計: 約2,240万円

【3年目以降】
  保守社数が増え続ける → ストック収入が主軸に
  AI進化で1人が保守できる社数が増加 → 利益率向上
```

## 5. 競争優位性・参入障壁

### 大手が参入しない理由

1. **市場が小さい** — 中小企業のバックオフィス自動化市場はSaaS化できない
2. **標準化できない** — 企業ごとに業務フロー・使用ソフトが異なりフルスクラッチ必須
3. **泥臭い現場作業** — 出向してヒアリング・セットアップが必要。スケールしない

### 非エンジニアが参入できない理由

| 障壁 | 横原の強み |
|------|-----------|
| フルスクラッチ実装力 | 20年の開発経験。JS/PHP/Python/TS/SQL全対応 |
| API連携・データパイプライン構築 | REST API設計・DB設計・ETLの豊富な実績 |
| AI活用の深い理解 | OpenAI API実装・RAG構築・プロンプト設計の実務経験 |
| インフラ・セキュリティ | サーバー構築・ネットワーク・セキュリティ設計の知識 |
| デバッグ・障害対応 | 自動化が壊れたとき直せる。20年分の問題解決力 |
| 業務理解力 | HP制作を通じた多業種の中小企業業務への理解 |

## 6. 事業ポートフォリオ全体像

### 2つの柱

```
オフィセイト（横原聖八）
├── 【柱①】AIホームページビルダー（ai-hp-builder）
│   ├── 完全自宅型・オンラインサービス
│   ├── 2026年夏リリース予定
│   ├── 短期的にはこちらが主力
│   └── AI発達とともに市場縮小の可能性あり
│
└── 【柱②】shinjin.ai（業務完全自動化サービス）
    ├── 出向+自宅のハイブリッド型
    ├── 2026年夏以降に実績を積む
    ├── 中長期的にこちらがメインに成長
    └── AI進化で価値が上がり続ける構造
```

### 相乗効果

- **ai-hp-builder顧客 → shinjin.aiを提案**（クロスセル）
- HP制作で信頼関係を構築済みの企業に、業務自動化も提案できる
- 集客チャネルを共有可能（SNS・YouTube・自社HP・リスティング広告）
