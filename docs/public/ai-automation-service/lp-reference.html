社長〜！今年の新人はAIにしていいですか？

shinjin.ai

中小企業の経理・総務・管理部門に、休まず働く「新人AI」を配属する。転記、確認、メール、PDF、Excelを1業務ずつ安全に自動化します。

自動化できる業務を相談する 実績の裏付けを見る
  • 初期構築1人月100万円〜
  • 1業務を1ヶ月で構築
  • 人間確認を残す安全設計

POSITIONING

AI導入ではなく、業務が回る仕組みを納品する

汎用SaaSや研修では埋まらない、現場固有の例外処理まで見る。ヒアリング、設計、実装、導入、保守を横原聖八が一気通貫で担う直契約サービスです。

1業務だけ選ぶ

請求書、メール分類、CSV取込、月次集計など、最初は小さく始めて成果を見せます。

既存環境を活かす

Excel、Web管理画面、SaaS、既存DBを読み解き、APIやブラウザ自動化でつなぎます。

例外は人が見る

AI判定を鵜呑みにせず、低信頼・失敗・重要操作はSlack通知や承認で止めます。

現場に残る負担

  • !担当者しか分からないExcelや手順が多い
  • !請求書、注文書、メール、PDFの転記が毎月発生する
  • !SaaSを入れても現場固有の例外に合わない
  • !採用、教育、引き継ぎ、退職リスクが重い

新人AIの役割

  • ✓入力、確認、分類、通知、レポート化を自動化
  • ✓既存の業務システム、メール、DB、Slackをつなぐ
  • ✓判断が必要な箇所だけ人間確認に回す
  • ✓保守で業務変更やAI精度改善を継続する

TARGET

向いている会社と、最初は慎重にしたい相談

新人AIは、現場の手順がある程度見えていて、毎月同じような確認・転記・集計が発生する会社ほど相性が良いです。

向いている会社

  • 経理・総務・管理部門に手作業が多い
  • Excel、PDF、メール、既存システムの転記が多い
  • 新人1人分の採用費・人件費・教育コストを置き換える発想がある
  • 追加IT予算ではなく、人件費の振替として初期構築1人月100万円を判断できる
  • まず1業務だけ小さく試したい

最初は慎重に扱う相談

  • 医療・法務・与信など、AI判断ミスが重大事故になる業務
  • 電話対応など、リアルタイム対外対応が中心の業務
  • 現場の手順がまだ固まっていない業務
  • 全社DXを一気に進めたい大型案件
  • 人間確認を完全になくすことが前提の業務

DELIVERABLES

1ヶ月で納品するものを、最初から明確にする

初期構築1人月100万円は、相談だけではなく「動くもの」「確認できるもの」「保守できるもの」までを含める前提です。

初期構築で作るもの

  • 対象業務の処理フロー整理
  • 入力データの取込・検証処理
  • AI抽出・分類・要約・判定の実装
  • 人間確認用の画面または通知
  • 出力データ、レポート、既存システム連携
  • 操作手順と保守観点のドキュメント

安全設計

AI判定をそのまま信じず、ルール判定、データ検証、低信頼時の停止、人間承認、ログ確認を組み合わせます。

月額保守

AIは日進月歩です。納品後も、業務変更、障害対応、AIチューニング、ログ確認、例外パターン追加を継続して、新人AIを育てます。

拡張方針

最初の1業務で成果が出たら、同じ入力・通知・確認の仕組みを横展開し、2人目・3人目の新人AIにつなげます。

PRICE LOGIC

「IT投資」ではなく、新人1人分の人件費枠で比べる

大阪の新卒オフィスワーカーを前提に、月給だけでなく賞与、残業代、交通費、会社負担、採用教育、OJT、管理工数、備品/SaaSまで含めて比較します。新人AIは、定型業務を担う人件費枠の振替として見せます。夜間や休日の処理にも回せるので、遅刻・欠勤・教育の個人差・早期退職・引き継ぎ漏れといった新人採用時の不確実性も抑えられます。

大阪労働局の新規学卒者初任給情報、社会保険料率、採用教育コストをもとにしたLP用概算です。実際の見積では対象業務と現場の人件費前提に合わせて調整します。

比較の前提

  • 比較対象は大阪府の新卒事務職に固定する
  • 新人さん側は月給、賞与、残業代、交通費、採用費、教育/OJT、備品/SaaSまで含める
  • 会社負担は社会保険、交通費、福利厚生の端数込みで給与・賞与・交通費等の20%として置く
  • 新人AIは初期構築100万円、保守は初期構築の15%で試算し、2年目は保守のみで見る
  • 24時間365日稼働でき、欠勤・教育の個人差・早期退職・引き継ぎ漏れの不確実性を減らせる

今回の比較条件

  • 比較対象は新卒。中途、派遣、パート、既存社員とは比べない
  • 新人さんに実際かかる費用は全部含める
  • 対象業務はAIに有利めに置く。件数が多く、繰り返しが多く、夜間・休日にも処理できる業務を選ぶ
  • 2年目は保守のみ。追加業務の初期構築は別見積にする

FAQ

問い合わせ前の不安を減らす

最終LPでは、この中から問い合わせの多い質問だけを残します。初回相談では、完璧な要件定義より「困っている手作業」を持ってきてもらう方が早いです。

何から相談すればいいですか？

毎月時間を取られている手作業を1つ教えてください。請求書、メール、Excel、PDF、転記、確認作業のどれかで十分です。

既存システムを変えずにできますか？

API連携、CSV取込、ブラウザ自動操作、確認画面の追加など、既存環境を活かす方法から検討します。

AIが間違えたらどうしますか？

最初から完全自動にせず、低信頼・例外・重要操作は人間確認に回します。ログを見ながら例外パターンを追加します。

小さく試せますか？

はい。最初は1業務・1ヶ月の初期構築から始めます。効果が出たら、周辺業務へ広げる方針です。

相談前にあると良い情報

  • 対象業務の手順書、チェックリスト、現場メモ
  • 入力に使うPDF、Excel、CSV、メールのサンプル
  • 出力したい帳票、CSV、Slack通知、レポートの形
  • 月間件数、1件あたりの作業時間、ミスが起きやすい箇所
  • 絶対に自動実行せず、人間確認を残したい操作
